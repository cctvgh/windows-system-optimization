# Windows 系统优化（windows-system-optimization）

Windows 整机优化技能：开机自启项审计清理、磁盘空间扩容（缓存清理 + 符号链接迁移 + 页面文件迁移）、运行性能调优与激活状态检查。面向**企业安全管控机器**设计——安全/合规/终端管控软件绝不触碰，拿不准的项一律交用户确认。

## 特性

- **自启项全源审计**：HKLM/HKCU Run 与 RunOnce、启动文件夹、登录/开机计划任务、自启服务、StartupApproved 历史残留，六个数据源缺一不可
- **三分类处理**：不能动（安全软件、系统核心）/ 明显多余（古董预加载器、云主机初始化、重复更新器）/ 拿不准（日常软件，分组多选让用户勾选）
- **磁盘扩容三板斧**：缓存与日志清理、大目录 `robocopy` + `mklink` 符号链接迁移（源/目标差异 <5% 才删源）、页面文件迁至数据盘
- **运行调优**：视觉效果与启动延迟、TCP 参数、事件日志限额、碎片整理（先分析后整理、后台轮询）、`sfc /scannow` 结果经 CBS.log 校验
- **安全护栏**：改注册表前 `reg export` 备份、计划任务只禁用不删除、迁移不卸载、系统级修改注明"重启后生效"
- **受保护服务识别**：改不动 ≠ 权限问题，识别安全软件注册表保护后立即停止提权尝试，避免触发安全告警

## 快速开始

1. 把本目录放到技能目录下（或让智能体加载 `SKILL.md`）。
2. 直接描述诉求，例如：

```
C盘只剩 8G 了，帮我看哪些能清理、哪些能迁到 D 盘
```

```
开机太慢，帮我审计一下自启项，能关的列出来让我选
```

3. 助手按"扫描（只读）→ 分类 → 用户确认 → 备份 → 执行 → 验证 → 报告"推进，并输出"关了哪些/没动哪些/预计快多少/如何恢复"四段式报告。

## 安全提示

- 杀毒、终端管控、零信任 VPN、堡垒机、文档加密、SDP 接入、网管客户端、输入法（ctfmon）**一律不动**
- 所有修改前先备份；不确定的项目交用户决定，不替用户判断
- 涉及服务禁用、页面文件迁移、视觉效果调整时，提示用户保存工作后再重启
- 仅提供合规的激活途径（单位 IT / KMS、机箱 COA、微软客服），不提供破解工具与密钥
